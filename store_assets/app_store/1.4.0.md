# 1.4.0 の App Store 提出用文言

1.3.0（ビルド29）から1.4.0（ビルド30）で変わったところをもとに書いた文言。

1.3.0は App Store Connect で READY_FOR_SALE（公開済み）なので、「このバージョンの新機能」は1.3.0からの差分だけを書く。

アプリの中身で変わったのは次の点。

- アプリを一定期間継続してご利用いただいた方に、App Store での評価（レビュー）をお願いする仕組みを追加しました（#198）
- 「設定」>「このアプリについて」に「アプリを評価する」メニューを追加し、いつでもストアを開いてレビューを書けるようにしました（#198）

バージョンを1.3.1ではなく1.4.0にした。不具合の修正だけでなく、新しい機能・導線が加わるため。

括弧内は App Store Connect の入力欄の上限文字数。

## このバージョンの新機能（4,000字）

```
いつも「さいたま市ゴミ収集カレンダー」をご利用いただきありがとうございます。

■ アプリの評価をお願いする仕組みを追加しました
アプリを一定期間継続してご利用いただいた方に、アプリ内から簡単に評価を送信していただける案内を表示するようにしました。急いでごみ出しを確認する起動直後ではなく、操作が一段落したタイミングで控えめに表示します。

■ 「このアプリについて」からいつでもレビューを書けるようにしました
設定画面の「このアプリについて」に「アプリを評価する」を追加しました。いつでも App Store のレビュー画面を開いて、ご意見や応援のメッセージをお寄せいただけます。

外部のサーバーと通信しない方針や、個人情報を取得しない方針はこれまでどおりです。
```
