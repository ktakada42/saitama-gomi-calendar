# 1.3.0 の App Store 提出用文言

1.2.0（ビルド24）から1.3.0（ビルド29）で変わったところをもとに書いた文言。
ビルド25〜28は実機確認で見つかった点を直す前のもので、提出には使わない。

**2026-10-02 08:41（JST）に審査へ提出した。** 実機での確認（#157）は済んだ。
App Store Connect API でバージョン1.3.0を作り、下の文言を入れ、ビルド29を紐づけ、
スクリーンショットの4枚目を差し替え、`reviewSubmissions` を作って提出まで済ませてある
（`WAITING_FOR_REVIEW`）。承認後は自動でリリースされる（`AFTER_APPROVAL`）。

1.2.0は App Store Connect API で確認したところ READY_FOR_SALE、つまり
すでに公開済みなので、「このバージョンの新機能」は1.2.0からの差分だけを書く。

アプリの中身で変わったのは次の3つ。

- 10月1日のプラスチックの分別変更を、分別の一覧に反映した（#155）
- 市の資料から取り込むときに落ちていた注意書き81件と2品目を戻した（#155）
- 分別変更の知らせを畳めるようにした（#156）
- 注意書きを、但し書きごとに改行するようにした
- 実機確認で見つかった3点を直した（英数字の全角・半角の統一と重複していた
  CDの解消、分別変更の印の色、変更より前の日の区分の説明）

バージョンを1.2.1ではなく1.3.0にした。不具合の修正だけでなく、これまで
無かった表示（資源物1類に出せる条件、足した品目、知らせの開け閉め）が
増えるため。知らせを足した1.2.0と同じ扱いにしている。

括弧内は App Store Connect の入力欄の上限文字数。

## このバージョンの新機能（4,000字）

```
10月1日からのプラスチックの分別変更を、分別の一覧に反映しました。

■ プラスチックの分別変更を反映しました
さいたま市は令和8年10月1日から、歯ブラシ・ストローなどのプラスチック製品を「資源物1類（プラスチック資源）」として集めています。市の資料が品目を示しているものを、分別の一覧に反映しました。

・歯ブラシ、ストロー、定規、プラスチック製のスプーンとフォークを、資源物1類にしました。
・市が早見表で印を付けている23品目（タッパー、洗面器、おもちゃ、バケツなど）には、「プラスチック製で30cm未満なら資源物1類」と出します。材質や大きさで出し先が変わるので、区分はそのままにして条件を添えています。
・クリアファイル、CDケース、気泡緩衝材など、市のリーフレットに載っている7品目を足しました。

■ 欠けていた注意書きを戻しました
「金属製は、もえないごみ」「液体のものは、排出禁止」など、およそ80品目の注意書きが一覧に出ていませんでした。市の資料から取り込むときに落ちていたものです。同じ理由で抜けていた2品目（じょうろ、車用のジャッキ）も足しました。

調べられる品目は498品目から506品目になりました。

品目名の英数字は半角にそろえました（「CD」「Tシャツ」など）。全角と半角で2つ並んでいた「CD」は1つにまとめています。全角で打っても半角で打っても検索できます。

■ 注意書きを読みやすくしました
1つの品目に但し書きがいくつかあるとき、区切りなしでつながって出ていました（「回収ボックスへもえないごみとしても出せます」など）。但し書きごとに行を分けました。

■ 分別変更の知らせを畳めるようにしました
分別の画面の上に出る知らせは、見出しを押すと畳めます。一覧を送り始めたときや、検索を始めたときにも畳まれます。

■ カレンダーの過去の日は、当時の決まりで出します
9月以前の日を開いたときは、資源物1類の説明を変更前の「容器包装プラスチック」で出します。

■ そのほか
・分別変更の知らせと、品目の注意の印を、同じ黄色系の注意の色にそろえました。
・カレンダーの収集がない日は押せなくしました（年末年始を除く）。押して出るシートが細くなっていたのも直しました。

端末の中だけで完結する点、サーバーと通信しない点はこれまでどおりです。
```

## 説明（4,000字）

骨格は1.2.0のまま、品目数の2か所だけを直す。

1. 「■ 498品目の分別を、五十音で探せる」→「■ 506品目の…」
2. 本文の「…品目を補って、498品目を収録しました」→「…506品目を収録しました」

506は、早見表448件（落ちていた2品目を戻した）に、図解のページからの補い51件と、
プラスチックの分別変更で足した7件を合わせた数。補いは52件だったが、早見表の
「ＣＤ」と同じものを「CD」として足していたので、1件減らした。

説明は「このバージョンの新機能」と違って前の版から引き継がれるだけなので、
この2か所を書き換えた（`PATCH /v1/appStoreVersionLocalizations/{id}`
の`description`）。

## App Review に関する情報（審査メモ）

1.0.0からの日英併記をそのまま残し、「今回の変更」の節だけを1.3.0のものに
差し替える。

1.2.0のときは、知らせが端末の日付によって出ないことを断っていた。いまは
10月1日を過ぎているので、普通に起動すれば出る。その断りは外す。

審査メモは全体で4,000字まで。日英の「今回の変更」をそのまま足すと4,237字に
なったので、節を詰めた（全体で3,836字）。カレンダーで収集のない日が押せなく
なったことは書いておく。担当者が押して何も起きないのを不具合と取らないように。

```
■ 今回の変更（1.3.0）について

さいたま市が令和8年（2026年）10月1日からプラスチックの分別を変更したため、
同梱している分別の一覧を市の資料に合わせて更新しました。

・一部の品目の区分と注意書きを更新し、7品目を追加しました。
・取り込みの際に欠けていた注意書きと2品目を補いました。
・「分別」タブ上部の変更の知らせを、見出しを押して折り畳めるようにしました
  （折り畳んだかどうかは端末内に保存します）。
・「カレンダー」タブで、収集のない日は押しても何も開かないようにしました

更新した内容はすべて同梱データで、通信して取得するものではありません。
知らせの「市の最新の案内を見る」と「このアプリについて」の出典は、さいたま市の
告知ページ（https://www.city.saitama.lg.jp/001/006/010/003/p127278.html）を

```

## 変更しないもの

- 年齢制限（4+）、カテゴリ、価格
- プライバシー申告（データを収集しない）。知らせを畳んだかどうかは端末内の
  設定（`UserDefaults`）に保存するだけで、外へは出ない
- 暗号化の申告 — `ITSAppUsesNonExemptEncryption = false`
  （`ios/Runner/Info.plist`）
- iPhone専用（`TARGETED_DEVICE_FAMILY = 1`）。iPad用スクリーンショットは不要
- サポートURL（GitHubのIssues）
- キーワード・サブタイトル

## スクリーンショット

**4枚目（`03_dictionary.png`）だけ撮り直した。** ほかの4枚（ホーム・ウィジェット・
カレンダー・設定）は、今回の変更では見た目が変わらない。

4枚目は2つの理由で古くなっていた。

- コピーの「498品目」が506品目になった
- 分別の画面の上に、変更の知らせが出るようになった（10月1日を過ぎたため）。
  前のスクリーンショットには写っていなかった

知らせは**畳んだ状態**で撮った。広げると画面の半分近くを占めて、一覧が
ほとんど写らない。このスクリーンショットで見せたいのは一覧のほうなので、
`flutter.sorting_notice_collapsed_plastic2026`を`true`にして起動している
（ほかの設定は`store_assets/screenshots/README.md`の手順どおり。地区は
1.1.1と同じ「南区 南浦和1〜4丁目」）。
