# 1.2.0 の App Store 提出用文言

1.1.1（ビルド23）から1.2.0（ビルド24）で変わったところをもとに書いた文言。

**2026-09-13 23:58（JST）に審査へ提出した。** App Store Connect API で
バージョン1.2.0を作り、下の文言を入れ、ビルド24を紐づけて提出まで済ませてある
（`WAITING_FOR_REVIEW`）。スクリーンショット・説明・キーワードは1.1.1から
自動で引き継がれた。承認後は自動でリリースされる（`AFTER_APPROVAL`）。

1.1.1は App Store Connect API で確認したところ READY_FOR_SALE、つまり
すでに公開済みなので、「このバージョンの新機能」は1.1.1からの差分だけを書く。

アプリの中身で変わったのは、10月1日の分別変更の知らせ（#143・#144）だけ。
ほかは依存の更新とCIの整備で、利用者の目に触れるものではない。

バージョンを1.1.2ではなく1.2.0にした。不具合の修正ではなく、これまで無かった
表示が増えるため。ウィジェットを足した1.1.0と同じ扱いにしている。

括弧内は App Store Connect の入力欄の上限文字数。

## このバージョンの新機能（4,000字）

```
10月1日からのプラスチックの分別変更をお知らせします。

■ 10月1日から、分別の画面に知らせが出ます
さいたま市は令和8年10月1日から、これまで「もえるごみ」だった歯ブラシ・ストローなどのプラスチック製品を「プラスチック資源」として集めます。このアプリに入っている分別はまだ変更前のものなので、10月1日を過ぎたら分別の画面の上に知らせを出します。市が挙げている3つの条件（プラスチック100％／いちばん長い辺が30cm未満／水で軽くすすいで汚れが落ちる）と、市の案内へのリンクを添えてあります。

品目ごとの新しい分別は、市が10月1日に公表する予定です。公表され次第、アプリの分別も入れ替えます。

端末の中だけで完結する点、サーバーと通信しない点はこれまでどおりです。
```

## プロモーションテキスト（170字）

**空のまま。** 1.1.1で空にしたときに「2026年10月のプラスチックの分別変更のように、
こちらの更新が間に合わなくても利用者に知らせたいことが出たときに使える」と
書いていたが、今回はアプリ自身が10月1日から知らせを出すので、ストアの文で
重ねて言う必要がない。サブタイトルと重複するという当時の理由も変わっていない。

市が品目別の分別を公表したあと、こちらのデータ更新が遅れるようなら、
そのときに使う。この欄は審査を通さずいつでも書き換えられる。

## キーワード（100字・カンマ区切り）

変更なし。検索で効いている語をいじる理由がない。

```
ごみ,ゴミ,ごみ出し,ゴミ出し,分別,ごみ分別,収集日,ごみの日,埼玉,埼玉県,浦和,大宮,岩槻,リマインダー,通知,ウィジェット,粗大ごみ
```

## 説明（4,000字）

変更なし。品目数（498品目）も、機能の説明も1.1.1のまま。
市が品目別の分別を公表してデータを入れ替えるときには、498という数が動く
可能性があるので、そのときに見直す。

## App Review に関する情報（審査メモ）

1.0.0からの日英併記をそのまま残し、末尾の「今回の変更」の節だけを
1.2.0のものに差し替えた。

**知らせは端末の日付が2026年10月1日以降のときだけ出る。** 審査の時点では
まだその日を過ぎていないので、担当者が普通に起動しても1.1.1と同じ画面になる。
確かめ方（端末の日付を変えて起動し直す）を書いておく。

```
■ 今回の変更（1.2.0）について

さいたま市が令和8年（2026年）10月1日からプラスチックの分別を変更するため、
その日以降にアプリ内で知らせを表示する機能を追加しました。

この知らせは端末の日付が2026年10月1日以降のときだけ表示されます。
審査時点で端末の日付がそれより前の場合、画面は1.1.1と変わりません。
表示をご確認いただく場合は、端末の日付を2026年10月1日以降に設定し、
アプリを起動し直してから「分別」タブをお開きください。

知らせの中の「市の最新の案内を見る」は、さいたま市の告知ページ
（https://www.city.saitama.lg.jp/001/006/010/003/p127278.html）を
外部ブラウザで開きます。アプリ自身が通信するものではありません。

追加した機能はこの知らせのみで、新しい権限は要求しません。
サーバーと通信しない点も1.0.0から変わっていません。
```

```
■ What is new in this version (1.2.0)

Saitama City changes its plastic waste sorting rules on October 1, 2026.
This version adds an in-app notice that appears on and after that date.

The notice is shown only when the device date is October 1, 2026 or later.
If the device date is earlier than that during review, the app looks exactly
as it did in 1.1.1. To see the notice, set the device date to October 1, 2026
or later, relaunch the app, and open the 分別 (sorting) tab.

The link inside the notice ("市の最新の案内を見る") opens Saitama City's
announcement page (https://www.city.saitama.lg.jp/001/006/010/003/p127278.html)
in an external browser. The app itself does not make network requests.

This notice is the only addition, and it requires no new permissions. As in
1.0.0, the app does not communicate with any server.
```

## 変更しないもの

- 年齢制限（4+）、カテゴリ、価格
- プライバシー申告（データを収集しない）
- 暗号化の申告 — `ITSAppUsesNonExemptEncryption = false`
  （`ios/Runner/Info.plist`）
- iPhone専用（`TARGETED_DEVICE_FAMILY = 1`）。iPad用スクリーンショットは不要
- サポートURL（GitHubのIssues）
- 説明・キーワード・サブタイトル
