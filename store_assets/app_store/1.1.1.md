# 1.1.1 の App Store 提出用文言

1.1.0（ビルド21）から1.1.1（ビルド23）で変わったところをもとに書いた文言。
**App Store Connect API で反映済み**（バージョン1.1.1を作り、ビルド23を紐づけ、
スクリーンショット6枚も入れ替え済み）。提出ボタンだけ押していない。

1.1.0は App Store Connect API で確認したところ READY_FOR_SALE、つまり
すでに公開済みなので、「このバージョンの新機能」は1.1.0からの差分だけを書く。

`pubspec.yaml`は1.1.1+22のまま出したが、同じ日にビルド22が先に上がっていたため、
App Store Connect 側が受け取ったときに23へ繰り上げた（ビルド番号の自動管理）。
アップロードした実体のInfo.plistは22だが、審査に出るのは23。リポジトリの
ビルド番号も23に合わせてある。

括弧内は App Store Connect の入力欄の上限文字数。

## このバージョンの新機能（4,000字）

```
分別の一覧の並び順を直しました。

■ 読みの五十音順に並ぶようになりました
一覧が読みの順になっていませんでした。「あ行」の先頭が「アイロン」の次に「アルバム」「アルミ箔」と続き、その後ろに「油」「網戸」が来ていました。市の分別早見表と同じ、読みの五十音順に並べ直しました。索引で行へ飛んだあと、目当ての品目のあたりを付けやすくなります。

■ 抜けていた3品目を足しました
「（車の）ホイール」「カセットボンベ（カートリッジ式ボンベ）」「マーガリン・バターの容器（プラスチック製）」が一覧に出ていませんでした。市の資料から取り込むときに落ちていたものです。調べられる品目は495品目から498品目になりました。

いずれも端末の中だけで完結します。通信しない点はこれまでどおりです。
```

## プロモーションテキスト（170字）

**空にした。** 1.1.0では「ホーム画面ウィジェットを追加しました」から始まる
文を入れていたが、外した。

この欄はプロダクトページの「説明」ブロックのいちばん上に、説明文の1行目として
続けて出る。独立した枠ではない。検索結果の一覧に出るのはサブタイトルのほうで、
そちらは「開いた瞬間に、明日のごみが分かる」が入っている。

外した理由は3つ。

- サブタイトルと同じことを言っている
- 説明文の1行目「さいたま市の家庭ごみの収集日と分別を確認するアプリです。」の
  すぐ上に、もうひとつ導入が挟まる形になる
- 中身が1.1.0の告知のままで、1.1.1では古い

**この欄は審査に出さずにいつでも書き換えられる**（バージョンを跨いで生き続け、
提出も要らない）。急いで伝えたいことができたときのために空けてある。
2026年10月のプラスチックの分別変更のように、こちらの更新が間に合わなくても
利用者に知らせたいことが出たときに使える。

## キーワード（100字・カンマ区切り）

変更なし。1.1.1で機能は増えていないので、効いている語をいじる理由がない。

```
ごみ,ゴミ,ごみ出し,ゴミ出し,分別,ごみ分別,収集日,ごみの日,埼玉,埼玉県,浦和,大宮,岩槻,リマインダー,通知,ウィジェット,粗大ごみ
```

## 説明（4,000字）— 1.1.0からの差し替え箇所

骨格は1.1.0のまま、品目数の2か所だけを直した。

1. 「■ 495品目の分別を、五十音で探せる」→「■ 498品目の…」
2. 本文の「…品目を補って、495品目を収録しました」→「…498品目を収録しました」

早見表そのものは443件から446件になった（落ちていた3品目を戻したため）。
498は、そこに図解のページからの補い52件を足した数。

## App Review に関する情報（審査メモ）

1.0.0からの日英併記をそのまま残し、末尾の「今回の変更（1.1.0）について」／
「What is new in this version (1.1.0)」の節だけを1.1.1のものに差し替えた。
機能も権限も増えていないことを、担当者が最初に読めるようにしてある。

```
■ 今回の変更（1.1.1）について

分別の一覧の並び順の修正です。読みの五十音順に並ぶようになりました
（これまでは同じ行の中で、カタカナの品目が漢字の品目より前に来ていました）。
あわせて、市の資料から取り込むときに落ちていた3品目
（「（車の）ホイール」「カセットボンベ（カートリッジ式ボンベ）」
「マーガリン・バターの容器（プラスチック製）」）を足し、調べられる品目が
495から498になりました。

機能の追加はなく、新しい権限も要求しません。サーバーと通信しない点も
1.0.0から変わっていません。
```

```
■ What is new in this version (1.1.1)

This version fixes the ordering of the sorting dictionary. Items are now listed
in Japanese phonetic (gojuon) order of their readings; previously, within the
same row, katakana items sorted before kanji items. It also restores three items
that had been dropped while extracting the data from the city's materials,
bringing the dictionary from 495 to 498 items.

There are no new features and no new permissions. As in 1.0.0, the app does not
communicate with any server.
```

## 変更しないもの

- 年齢制限（4+）、カテゴリ、価格
- プライバシー申告（データを収集しない）
- 暗号化の申告 — `ITSAppUsesNonExemptEncryption = false`
  （`ios/Runner/Info.plist`）
- iPhone専用（`TARGETED_DEVICE_FAMILY = 1`）。iPad用スクリーンショットは不要
- サポートURL（GitHubのIssues）

1.1.0からの変更点。

- **1枚目を「明日は何ごみ？」にした**。1.1.0では初回設定（地区選択）が先頭で、
  一覧に並ぶ1枚目が「まだ何もしていない画面」だった。アプリが何をするものかは
  ホームのほうが伝わる
- **初回設定の1枚を落とした**。地区を選ぶのは最初の一度きりで、売り場で
  見せたいものではない
- **ウィジェットのコピーを「ホーム画面から確認可能」にした**。「置いておける」は
  置けること自体を言っていて、置くと何が嬉しいのかが伝わらない。添え書きも
  「開かなくても明日が分かる」から「アプリを開かなくても明日のごみが分かる」に
  伸ばして、主語を補った
- **カレンダーの添え書きを外した**。「なぞって月をめくる」は操作の説明で、
  コピーの「ひと目で」と話が噛み合っていない
- **分別の添え書きを「あいまい検索も可能」にした**。「「椅子」でも「いす」でも
  引ける」は例として具体的だが、一覧の小さい字では読み解く手間がかかる

`03_dictionary.png` は今回の修正そのものが写る1枚。1.1.0のものは
「アイロン→アルバム→アルミ箔→油→網戸」と、直す前の並びがそのまま写っていた。

撮影に使った地区を「浦和区 大原1〜5丁目」から「南区 南浦和1〜4丁目」に変えた。
撮影日（2026-08-23・日曜）の翌日に収集がある区分の数で選んでいる。大原だと
月曜がもえるごみだけになり、ホームの「明日」もウィジェットも1区分しか
出ないため、南浦和（月曜がもえない・有害危険・資源物2類の3区分）にした。
