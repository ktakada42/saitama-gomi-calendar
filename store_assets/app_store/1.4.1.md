# 1.4.1 の App Store 提出用文言

1.4.0（ビルド30）から1.4.1（ビルド31）で変わったところをもとに書いた文言。

**2026-11-01 09:13（JST）に審査へ提出した。**
App Store Connect API でバージョン1.4.1を作り、下の文言を入れ、審査メモを更新し、ビルド31を紐づけ、
`reviewSubmissions` を作って提出まで済ませてある（`WAITING_FOR_REVIEW`）。承認後は自動でリリースされる（`AFTER_APPROVAL`）。

1.4.0は App Store Connect で READY_FOR_SALE（公開済み）なので、「このバージョンの新機能」は1.4.0からの差分だけを書く。

アプリの中身で変わったのは次の点。

- 「設定」>「このアプリについて」の「アプリを評価する」を押した際に、App Store のレビュー画面が開かなかった不具合を修正

括弧内は App Store Connect の入力欄の上限文字数。

## このバージョンの新機能（4,000字）

```
いつも「さいたま市ゴミ収集カレンダー」をご利用いただきありがとうございます。

■ 「このアプリについて」からレビュー画面を開けない不具合を修正しました
設定画面の「このアプリについて」にある「アプリを評価する」を押した際に、App Store のレビュー画面が開かない不具合を修正しました。

外部のサーバーと通信しない方針や、個人情報を取得しない方針はこれまでどおりです。
```

## プロモーションテキスト（170字）

**空のまま。** サブタイトルと重複するため使用しない。

## キーワード（100字・カンマ区切り）

変更なし。

```
ごみ,ゴミ,ごみ出し,ゴミ出し,分別,ごみ分別,収集日,ごみの日,埼玉,埼玉県,浦和,大宮,岩槻,リマインダー,通知,ウィジェット,粗大ごみ
```

## 説明（4,000字）

変更なし。

## App Review に関する情報（審査メモ）

1.0.0からの基本説明を残しつつ、「今回の変更」の節を1.4.1の内容に差し替えた。

```
■ 今回の変更（1.4.1）について

設定画面の「このアプリについて」にある「アプリを評価する」を押した際に、
App Store のレビュー画面が開かない不具合を修正しました。

機能の追加はなく、新しい権限も要求しません。サーバーと通信しない点も
1.0.0から変わっていません。
```

```
■ What is new in this version (1.4.1)

Fixed a bug where tapping "Rate this app" in Settings > About did not open the
App Store review page.

There are no new features and no new permissions. As in 1.0.0, the app does not
communicate with any server.
```
