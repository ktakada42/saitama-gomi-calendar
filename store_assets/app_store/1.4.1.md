# 1.4.1 の App Store 提出用文言

1.4.0（ビルド30）から1.4.1（ビルド31）で変わったところをもとに書いた文言。

1.4.0は App Store Connect で READY_FOR_SALE（公開済み）なので、「このバージョンの新機能」は1.4.0からの差分だけを書く。

アプリの中身で変わったのは次の点。

- 「設定」>「このアプリについて」の「アプリを評価する」を押した際に、App Store のレビュー画面が開かなかった不具合を修正

括弧内は App Store Connect の入力欄の上限文字数。

## このバージョンの新機能（4,000字）

```
いつも「さいたま市ゴミ収集カレンダー」をご利用いただきありがとうございます。

■ 「このアプリについて」からレビュー画面を開けない不具合を修正しました
設定画面の「このアプリについて」にある「アプリを評価する」を押した際に、App Store のレビュー画面が開かない不具合を修正しました。

外部のサーバーと通信しない方針や、個人情報を取得しない方針はこれまでどおりです。
```

## プロモーションテキスト（170字）

**空のまま。** サブタイトルと重複するため使用しない。
