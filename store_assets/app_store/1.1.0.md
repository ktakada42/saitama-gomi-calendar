# 1.1.0 の App Store 提出用文言

App Store Connect に貼り付けるための原稿。1.0.0（ビルド16）から
1.1.0（ビルド21）で変わったところをもとに書いた。

括弧内は App Store Connect の入力欄の上限文字数。

## このバージョンの新機能（4,000字）

```
ホーム画面ウィジェットを追加し、分別で調べられる品目を増やしました。

■ ホーム画面ウィジェット
アプリを開かなくても、明日は何ごみかがホーム画面で分かります。収集日の朝は、出す期限を過ぎるまで今日のごみを出し続けます。小サイズと横長の中サイズがあり、中サイズにはこの先の収集日も並びます。

■ 調べられる品目が443品目から495品目に増えました
市の早見表には載っておらず、図解のページにしかなかった品目（飲料の缶など）を補いました。

■ 言い換えでも引けるようになりました
市の書き方と、実際に打つ言葉のずれを埋めました。「椅子」で「いす」が、「iQOS」で「加熱式電子たばこ」が、「ルンバ」で「掃除機」が引けます。472品目・1,641語ぶんの言い換えを同梱しています。

■ 粗大ごみの料金と申込み先
持ち込みと戸別収集それぞれの手数料・予約先・手順を、品目の詳細から直接開けます。

■ 市で収集できないものの持って行き先
販売店やメーカー、専門の取扱業者など、12種類の持って行き先を品目から引けます。

■ 回収ボックスの場所
小型家電・電池の回収ボックスがある場所を、設定した区のものから出します。

いずれも通信は必要ありません。収集日も分別も、これまでどおり端末の中だけで完結します。
```

## 説明（4,000字）— 1.0.0からの差し替え箇所

説明文はほぼそのままでよい。次の2か所だけ直す。

1. 分別の品目数「443品目」→「495品目」
2. 機能の並びに、ウィジェットの節を足す（ホームの説明のすぐ後ろ）

```
■ ホーム画面ウィジェット
明日は何ごみかを、アプリを開かずにホーム画面で確認できます。収集日の朝は、
出す期限を過ぎるまで今日のごみを表示します。小サイズと横長の中サイズがあります。
```

## App Review に関する情報（審査メモ）

```
本アプリは、さいたま市が公開している資料（家庭ごみの出し方マニュアル等）をもとに
個人が作成した非公式アプリです。さいたま市とは関係がありません。その旨を
アプリ名（さいたま市ゴミ収集カレンダー（非公式））と、アプリ内の
「このアプリについて」画面に明記しています。

- アカウント登録・ログインはありません。デモアカウントは不要です。
- 位置情報・連絡先などの個人情報は取得しません。端末に保存するのは、利用者が
  選んだ地区・通知の設定・画面の明るさの設定だけです。
- サーバーとの通信はありません。出典としてさいたま市の公式ページを開くときだけ、
  外部ブラウザ（Safari）が起動します。
- 通知は端末内のローカル通知のみです（収集日の前日、利用者が指定した時刻）。
- 今回追加したホーム画面ウィジェットは、App Group を通じてアプリ本体が書き出した
  収集日データを読むだけで、新しい権限は要求しません。
```

## 変更しないもの

- 年齢制限（4+）、カテゴリ、価格
- プライバシー申告（データを収集しない）— 収集する項目は1.0.0から変わっていない
- 暗号化の申告 — `ITSAppUsesNonExemptEncryption = false`
  （HTTPS以外の暗号化を使っていないため輸出規制の対象外。`ios/Runner/Info.plist`）
- iPhone専用（`TARGETED_DEVICE_FAMILY = 1`）。iPad用スクリーンショットは不要
