# 1.5.0 の App Store 提出用文言

1.4.1（ビルド31）から1.5.0（ビルド36）で変わったところをもとに書いた文言。
ビルド32〜35は iOS 26 での表示・操作性やホーム画面ウィジェットの描画不具合を直す前のもので、提出にはビルド36を使う。

**App Store Connect API で提出直前の状態（`PREPARE_FOR_SUBMISSION`）まで反映済み**
（バージョン1.5.0を作り、下の文言と審査メモを入れ、ビルド36を紐づけ、スクリーンショット5枚も iOS 26 の画面で差し替え済み）。
提出（`reviewSubmissions` の `submitted: true`）だけ押していない。承認後は自動でリリースされる設定（`AFTER_APPROVAL`）。

1.4.1は App Store Connect で READY_FOR_SALE（公開済み）なので、「このバージョンの新機能」は1.4.1からの差分だけを書く。

アプリの中身で変わったのは次の3つ。

- iOS 26 以降の Liquid Glass デザインに対応し、アイコン・ウィジェットの外観カスタマイズにも対応した（#215・#219・#222・#225）
- 分別辞典の検索履歴を端末内に最大10件保存し、1タップで再検索できるようにした（#211）
- 設定画面の「画面の明るさ」を「外観」に改め、ボトムメニュー選択状態の視認性を改善した（#213）

不具合の修正だけでなく、検索履歴の追加や iOS 26 向けの画面・外観対応が入るため、バージョンは1.4.2ではなく1.5.0にした。

括弧内は App Store Connect の入力欄の上限文字数。

```

```

## App Review に関する情報（審査メモ）

1.0.0からの基本説明を残しつつ、「今回の変更」の節を1.5.0の内容に差し替えた。
検索履歴が外部送信されない端末内保存（`UserDefaults`）であることを日英で明記しておく。


## 変更しないもの

- 年齢制限（4+）、カテゴリ、価格
- プライバシー申告（データを収集しない）。検索履歴も端末内の設定（`UserDefaults`）に保存するだけで、外へは出ない
- 暗号化の申告 — `ITSAppUsesNonExemptEncryption = false`（`ios/Runner/Info.plist`）
- iPhone専用（`TARGETED_DEVICE_FAMILY = 1`）。iPad用スクリーンショットは不要
- サポートURL（GitHubのIssues）
- 説明・キーワード・サブタイトル
